# 🛡️ RON_CORE // Ultimate Tactical Linux Voice Assistant

**RON_CORE (v12.0)** is an advanced tactical voice assistant and cyber grid daemon built specifically for Linux environments (optimized for Kali Linux). It features a stunning holographic PyQt6 cyber canvas interface, dual-language voice recognition, and real-time shell execution.

---

## 🚀 Key Features

* **Holographic CyberCanvas:** Real-time node network visualization that dynamically reacts to active commands.
* **Dual-Language Support:** Seamless intent parsing and voice recognition for **Arabic (العربية)** and **English**.
* **Google Assistant-Style Flow:** Non-blocking listening and execution pipeline.
* **Tactical Linux Integration:** Direct voice-to-CLI mapping for directory management, network scanning (`nmap`), and system updates (`apt`).

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash

   cd ron-core-linux

2.
Create and activate a virtual environment:


python3 -m venv venv
source venv/bin/activate

3.
Install dependencies:

pip install --upgrade pip PyQt6 SpeechRecognition pyaudio

4.
Launch the core engine:


python3 core_engine.py
